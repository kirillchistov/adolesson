# Концепция приложения: семейная поддержка учёбы без качелей

Версия 0.1 · 18.11.2026 · рабочее название — «Ровно» (заменить по вкусу)

Источник: [support-concept.md](support-concept.md) (черновой план на 8 недель + референсы) и опыт прототипа [betty-rules](https://github.com/kirillchistov/betty-rules) («Мой курс»).

---

## 0. Суть в пяти строках

1. Это не трекер оценок и не «родительский контроль», а **общий инструмент семьи для 8-недельного эксперимента**: понять, где ломается учёба, и собрать посильную систему.
2. **Два входа — две разные программы.** Родитель получает тренажёр своей части (тон, паузы, разговоры, школа). Подросток — взрослый, эстетичный инструмент для старта, состояния и «своего».
3. **Между ними — «общий стол»**: только то, что подросток или родитель сами туда положили (договорённость недели, цвет светофора, просьба о помощи, встреча на 15 минут).
4. **Мини-диагностика = карта барьеров, а не ярлык.** Ответ на вопрос «где застревает: начать, понять, продолжить, сдать, восстановиться?» + маркеры, когда нужен специалист.
5. **Приватность подростка обеспечена архитектурой, а не обещанием**: личный журнал физически не уходит на сервер.

## 1. Что меняется относительно черновика

| Черновик (документ) | В приложении |
|---|---|
| 18 разделов, читать подряд | Маршрут по неделям: в каждой неделе открыто 2–4 действия, остальное — справочник |
| Чек-листы с галочками | Чек-листы без счёта и процентов; «сегодня было?» вместо «выполнено на 60%» |
| Рабочие листы с прочерками | Пошаговые формы на 1 экран = 1 вопрос; пустые поля разрешены |
| Светофор — договорённость на словах | Подросток ставит цвет в 1 тап, родитель видит только цвет и подсказку «что это значит для меня сегодня» |
| «Точная просьба» — пример фраз | Кнопка «Попросить помощь»: шаблон → отправка родителю в общий стол |
| Фразы на замену — список | Свайп-тренажёр и диалоговые квесты для родителя |
| Диагностика — список вопросов | Мини-диагностика из 3 модулей (см. §4) с итогом-картой и маршрутизацией |
| Референсы (Headspace, Choices, Breathwrk, Peak) | Взяты механики, но отфильтрованы через принципы плана (см. §7) |

Главная коррекция референсов: **никаких стриков, очков за объём и «удвоения после удачного дня»** — это прямо противоречит правилу плана «хороший день не создаёт долг продуктивности». Удержание строим на смысле и самоузнавании, а не на страхе потерять серию.

## 2. Роли, вход и модель приватности

### 2.1. Пространство семьи

- Родитель создаёт **пространство семьи**, приглашает второго взрослого (опционально) и подростка по ссылке/QR.
- У подростка **свой вход** (своё устройство, свой пароль/PIN). Родитель не может войти «за неё» и не видит её экранов.
- Подросток может пользоваться своей частью **без подключения к семье** (локальный режим, как в betty-rules) и подключиться позже. Это снимает ощущение «приложение — шпион».

### 2.2. Три слоя данных

| Слой | Где хранится | Кто видит | Примеры |
|---|---|---|---|
| **Личное подростка** | Только на устройстве (IndexedDB), экспорт файлом | Только она | Минутный журнал, чек-ин состояния, заметки, «Моё», результаты самодиагностики |
| **Личное родителя** | Сервер, доступ только автору (и второму взрослому — по выбору) | Родитель(и) | Наблюдения, свои реакции, чек-листы, журнал срывов, контакты школы |
| **Общий стол** | Сервер, доступ всем участникам семьи | Все | Договорённость недели, цвет светофора, просьбы о помощи, итоги встречи на 15 минут, карточки, которыми поделились |

Правило переноса: **из личного в общее — только явным действием автора** («Положить на общий стол»), с предпросмотром того, что увидят другие. Обратного пути (общее → личное другого) нет.

### 2.3. Безопасность и границы конфиденциальности

Объясняется **в онбординге обоих**, до первого использования (п. 3 «Как обращаться за помощью»: границы уточняют заранее):

- Приложение **не читает и не пересылает** записи подростка и **не отправляет родителям автоматических тревог** — скрытая слежка разрушает доверие, а автоматические детекторы дают ложные срабатывания.
- Если в чек-ине выбран «красный» или отмечены признаки из §16 (мысли о нежелании жить, самоповреждение), подросток **сразу** видит экран помощи: телефоны экстренных служб и линии доверия (для РФ — 112 и детский телефон доверия 8-800-2000-122), кнопку «Написать своему взрослому» (из её Карточки, §15) с готовым текстом.
- Родителю — честно: «Приложение не заменяет наблюдение и не сообщит вам о кризисе. Вот признаки, при которых нужно действовать, и что делать».

> Эту схему стоит проверить с психологом до запуска: решение «не уведомлять автоматически» — осознанный этический выбор, его надо формулировать аккуратно.

## 3. Карта приложения

```
┌──────────── Вход ────────────┐
│  Я родитель   │   Я подросток │
└──────┬────────┴──────┬────────┘
       │               │
  РОДИТЕЛЬ          ПОДРОСТОК
  ─────────         ─────────
  Неделя (маршрут)  Сейчас (чек-ин → одно действие)
  Перед разговором  Старт (первый шаг + блок)
  Пауза (SOS)       Помощь (точная просьба)
  Тренажёр фраз     Практики (дыхание, фокус)
  Наблюдения        Квесты
  Школа и специалисты  Моё (затеи из betty-rules)
  Справочник        Карточка и коллекция
            \       /
           ОБЩИЙ СТОЛ
   договорённость · светофор · просьбы
   встреча на 15 минут · итоги недели
```

### 3.1. Родитель: основные экраны

1. **Неделя** — главный экран. Номер недели маршрута (§4 черновика), её цель одной фразой, 2–4 действия «вам / ей / вместе», критерий недели («можно сказать "не понимаю" без лекции»). Кнопка «Неделя не получилась — что вернуть?» вместо «провал».
2. **Перед разговором** — чек-лист §6 как пошаговый фильтр. Если первые два пункта «нет» → экран «Сначала пауза. Когда вернётесь к теме?» с напоминанием на выбранное время.
3. **Пауза (SOS)** — одна большая кнопка в любом месте приложения. Протокол §10 с таймингами UNICEF (U4, U9): «я раздражён, беру паузу» → отойти, 20 секунд остыть, 5 медленных вдохов → по возможности 5–10 минут в другом месте → короткая подсказка → «Вернуться в обещанное время» (таймер). После — опционально «Восстановить контакт»: шаблон фразы признания своей части.
4. **Тренажёр фраз** — карточки §11: на лицевой стороне привычная фраза, свайп → замена и почему. Плюс диалоговые квесты (см. §5).
5. **Наблюдения** — запись фактов без оценок. Мягкий «линтер ярлыков»: если в тексте «ленивая», «опять», «никогда» — подсказка переформулировать в действие («не начала», «не сдала»). Наблюдения затем используются в диагностике и подготовке разговора.
6. **Чек-листы** — ежедневный (§7) как вечерняя пятисекундная отметка «было / не было сегодня», без суммы и графиков успеваемости родителя. Еженедельный — встроен в подготовку встречи на 15 минут.
7. **Школа и специалисты** — трекер запросов: что спросили у учителя, что ответили, приоритет долгов (не бесконечный список), «вопрос репетитору» (§5), маршрут обращения за оценкой учебного профиля.
8. **Справочник** — полный текст плана в разделах, с поиском; всё, что не открыто на этой неделе, доступно здесь.

### 3.2. Подросток: основные экраны

1. **Сейчас** — вход начинается с вопроса «Как ты сейчас?» (градиентный слайдер / выбор цвета, а не «чему учиться», референс 18.3). По ответу — одно предложение, не меню:
   - зелёный → «Старт» с договорённостью недели;
   - жёлтый → «уменьшенный блок»: минимальный объём из договорённости;
   - красный → восстановление (Д) и экран помощи; никакой учёбы.
2. **Старт** — техника «Только первый шаг» (В): записать конкретный результат блока («разобрать пример и два похожих»), таймер 5 минут → «продолжаю / хватит на сегодня» (оба варианта — нормальный исход). Блок 15–20 минут с одной строкой в конце (Е): «получилось / застряла на / следующий шаг».
3. **Помощь** — «Точная просьба» (Г): выбрать тип («не понимаю условие», «теряю знаки», «посиди рядом, не объясняя») → уточнить → отправить родителю на общий стол или скопировать учителю. Отдельно — «Мне можно сказать…» из Карточки.
4. **Практики** — дыхание (сфера, ритм, без задержек дыхания, с явной кнопкой «стоп, неприятно»), «Остановиться — назвать — выбрать» (А), фокус-разминка 60–90 сек. Ритуал перед учёбой = «2 мин дыхания + 1 мин фокуса» как «заряд батареи».
5. **Квесты** — ситуационные интерактивные истории (см. §5).
6. **Моё** — встроенный «Мой курс» из betty-rules: свои затеи (рисунок, одежда, танцы, музыка), попытки, истории, мантры. Здесь не учёба, а восстановление и идентичность — «не любой отдых обязан быть полезным». Подробности встраивания — §9.4.

Нижняя навигация подростка: **Сейчас · Старт · Моё · Я**; «Попросить помощь» — плавающая кнопка на всех экранах, кроме кризисного.
7. **Профиль и карточка** — Карточка подростка (§15), коллекция карточек-инсайтов, карта барьеров (личная), тема оформления.

### 3.3. Общий стол

- **Договорённость недели** (лист §12) — создаётся вместе на встрече; черновик может начать любой, вступает в силу, когда оба нажали «согласна / согласен». Поле «Чего родители не делают» обязательно.
- **Светофор** — текущий цвет (ставит подросток; родитель может отметить свой цвет отдельно). У родителя рядом с цветом — что это меняет: «Жёлтый: одна главная задача, без дополнительной проверки».
- **Просьбы о помощи** — лента: просьба → «вижу» → «приду в 19:00» / «давай завтра». Без счётчиков «сколько раз просила».
- **Встреча на 15 минут** (лист §14) — пошаговый сценарий с таймером: 2 успеха → 1 барьер → что говорит она → что меняют родители → одно изменение. Итог автоматически становится черновиком следующей договорённости.
- **Одно согласованное напоминание** (§5–6 недели) — единственное push-напоминание об учёбе, которое родитель может «отправить», и только в согласованное время.

## 4. Мини-диагностика: «карта барьеров»

### 4.1. Принципы

- Это **сбор наблюдений для разговора и для специалиста**, не диагноз. Каждый итог содержит фразу: «Это не объясняет причину. Это показывает, где проверять дальше».
- Итог — **профиль**, а не балл: радар-карта по пяти точкам цикла, меняется со временем, сравнивается только со стартом самого человека.
- Три перспективы одного вопроса: **подросток о себе**, **родитель о наблюдаемом**, **педагог (по желанию, через родителя)**. Расхождения — тема разговора, не спор «кто прав».
- Короткие сессии: модуль ≤ 3 минут, можно бросить и вернуться.

### 4.2. Модуль A — «Где ломается» (подросток, ~3 мин, неделя 1–2)

Пять точек цикла учебной задачи, по 2–3 карточки-ситуации на каждую, ответ свайпом «про меня / не про меня / иногда»:

| Точка | Пример карточки |
|---|---|
| **Начать** | «Знаю, что делать, но открыть тетрадь — как стена» |
| **Понять** | «Читаю условие и не понимаю, что от меня хотят» |
| **Продолжить** | «Начала, но через 10 минут уже в телефоне / мысли уплыли» |
| **Сдать** | «Сделала почти всё, но не отправила / не принесла» |
| **Восстановиться** | «После рывка несколько дней ничего не могу» |

Плюс фон: сон (примерно часов), энергия, страх ошибки / реакции взрослых, что было иначе на удачной неделе.

**Итог**: карточка-инсайт «Твоя точка трения — старт. Попробуй "Только первый шаг" три раза на этой неделе» + радар. Делиться — по желанию, на общий стол уходит только текст, который она сама выбрала.

### 4.3. Модуль B — «Что вижу» (родитель, ~5 мин, неделя 1–2)

- Те же пять точек, но через конкретные эпизоды: «Опишите последний случай. На каком шаге остановилось?» — с выбором точки и полем факта.
- Вопросы §3 черновика: внимание и организация вне математики и вне дома; когда появилось; что говорят 2–3 взрослых; сон и самочувствие за неделю.
- Самопроверка петли (§1): «давление → обещание → рывок → спад» — было ли это в последний месяц? Где вступили вы?

**Итог**: сравнение с картой подростка (если она поделилась) — «вы видите проблему в "начать", она — в "понять"». Это готовая тема для первого разговора.

### 4.4. Модуль C — «Математика» (с педагогом/репетитором, неделя 2–4)

Структура из §5 черновика в виде формы для педагога (ссылка без регистрации или PDF):

- 3 ближайших пробела → по каждому: делает сама / нужна подсказка / держится через несколько дней.
- Классификатор ошибок: не знает правило · не выбирает способ · теряет последовательность · путает знаки · не понимает текст · не переносит на похожее. Отдельно геометрия: условие, чертёж, выбор свойства, объяснение переходов.
- Скорость на первом этапе не оценивается.

**Итог**: «карта трёх пробелов» на общем столе → выбор одной темы для блоков недель 3–4.

### 4.5. Маршрутизация: когда диагностика говорит «дальше — к специалисту»

Правила-триггеры, не меняющие тон, но показывающие родителю экран «Как обращаться за помощью» (§3, §16):

- Многолетние математические трудности при регулярных занятиях → оценка учебного профиля сейчас, не после 8 недель.
- Похожие трудности внимания/организации вне математики и вне дома, у нескольких наблюдателей.
- Устойчивая усталость при достаточном сне → врач.
- Повторяющиеся «красные» дни, ухудшение сна, аппетита, посещения, потеря интереса → профессиональная оценка раньше.
- Любые признаки риска для жизни → экран экстренной помощи немедленно.

Явная оговорка в интерфейсе: «Плохая математика не доказывает дискалькулию, рассеянность — СДВГ».

### 4.6. Повторная диагностика

Короткий повтор модулей A и B на 4-й и 8-й неделях → «было / стало» по пяти точкам + метрики §8.

## 5. Интерактивные форматы (адаптация референсов)

| Референс | Механика | У нас |
|---|---|---|
| Headspace «Wake Up», Deepstash | Сторис 3–5 экранов, прогресс-бар, карточка идеи | Короткие тексты из плана (для родителя: «почему не "ленивая"», для подростка: «почему старт — самое трудное») 2–3 мин, с кинетической типографикой |
| Choices / Episode, Wysa | Ветвящийся диалог | **Квесты**: подросток — «вечер перед контрольной», «долги по трём предметам», «родитель начал лекцию»; родитель — «она сказала "отстаньте"», «обещала и не сделала», «тройка за контрольную». Ветки показывают последствия тона, без «Game over» |
| Duolingo / Brilliant | Свайпы, drag-and-drop, мгновенная реакция | Тренажёр фраз (свайп), «миф / факт» про сон, мотивацию, СДВГ; сортировка ошибок по типам в модуле C |
| Breathwrk / Oak | Сфера, haptic, без слов | Дыхание и пауза. Haptic — только на Android (Vibration API в iOS Safari нет); на iOS — звук-метроном и визуальный ритм |
| Peak / Lumosity | Мини-игры 60–90 сек | Фокус-разминка как ритуал входа, **без обещаний «улучшить мозг»** и без рейтингов |
| Коллекционные карточки, темы | Награда смыслом | Карточка-инсайт после квеста/практики/встречи («Ты заметила, что начать легче после прогулки»); темы оформления из betty-rules (lunar, collage) + новые |

**Профиль навыков вместо оценок** — да, но только по навыкам саморегуляции и стратегии («умею просить точно», «знаю свой минимальный объём»), не по «силе воли» и не по оценкам.

## 6. 8-недельный маршрут в интерфейсе

| Неделя | Родитель (вкладка «Неделя») | Подросток | Общий стол | Критерий недели |
|---|---|---|---|---|
| 0 (72 часа) | Наблюдения ×3, кто ведёт разговор, отказ от сравнений; квест «первый разговор» | Онбординг, Карточка, чек-ин (без учёбы) | Приглашение в семью | Разговор состоялся без обещаний «исправить всё» |
| 1 | Модуль B, журнал своих реакций, тренажёр фраз | Модуль A, выбор канала «не понимаю» | 1 учебный приоритет | Можно сказать «не понимаю» без лекции |
| 2 | Запрос учителям (с её ведома), начать маршрут оценки при триггерах | Минутный журнал 5–7 дней (по желанию) | Карта: 1 барьер + 1 помогающий фактор | Барьер назван конкретно, не «мотивация» |
| 3–4 | Модуль C с педагогом, приоритет долгов со школой | Блоки 15–20 мин ×4/нед, «первый шаг», «точная просьба» | Первая договорённость, светофор | Блоки начинаются; просьбы точнее |
| 5–6 | Одно напоминание вместо многих; встреча 15 мин | Сама выбирает время, сама замечает затруднение | Еженедельная встреча, обновление договорённости | Меньше внешних напоминаний без роста напряжения |
| 7–8 | Повтор B, сравнение метрик | Повтор A | Итоговая встреча: что увеличиваем (одно: длительность / частоту / сложность) | Решение о следующем маршруте |

Ветвления маршрута: «стало устойчивее» → увеличить один параметр; «работает, но не закрепляется» → пересмотр обучения + оценка; «состояние хуже» → досрочный экран помощи. Кнопка «вернуть часть поддержки» доступна всегда.

**Контекст 9 класса**: ОГЭ весной. Приложение показывает срок только как фон для приоритизации долгов со школой; обратного отсчёта и «осталось N дней» на экране подростка нет.

## 7. Принципы продукта (фильтр для любых фич)

1. **Ни одна функция не превращается в инструмент наказания или доказательства в ссоре.** Родитель не видит журнал; на общем столе нет статистики «сколько не сделала».
2. **Без стриков и долгов.** Пропуск дня ничего не обнуляет. После хорошего дня приложение не предлагает «больше».
3. **Одно действие за раз.** Каждый экран предлагает один следующий шаг, а не список.
4. **Пустое — нормально.** Любое поле можно пропустить, любой модуль — бросить.
5. **Язык действий, не характера.** Тексты проходят редактуру на ярлыки; в UI нет «ленивая», «мотивация», «дисциплина».
6. **Взрослая эстетика для подростка.** Тёмная тема по умолчанию, mesh-градиенты, крупная типографика, никаких маскотов и мультяшности; тон — как в betty-rules: спокойный, без морали.
7. **Тихие уведомления.** У подростка — только те, что она сама включила. У родителя — напоминание о встрече и о своей паузе, не о её учёбе.
8. **Честность о доказательности.** Маршрут, светофор и формы — авторские организационные инструменты; это сказано в «О приложении» и в справочнике. У каждого приёма в контенте есть код источника из [sources.md](sources.md); где источника нет — так и пишем.

Опоры принципов в источниках: язык без ярлыков и объяснение откладывания через эмоции — S2, S3; поддержка вместо давления — S5, U1; выбор подростка и отказ от очков за объём — S6; конкретный результат перед блоком — S1; дыхание как практика без обещаний терапии — U5, S7; фокус-разминка без обещаний «прокачать мозг» — S8; тексты кризисного экрана — W5, W6, R1; дисклеймеры диагностики — W7, L1.

### 9.4. Встраивание betty-rules («Мой курс») как раздела «Моё»

**Решение:** betty-rules не остаётся отдельным приложением, а становится разделом «Моё» подростковой части. Его код — стартовая база всего фронтенда: Vite-конфиг, Makefile, workflow для Pages, токены тем, UI-компоненты.

#### Как переносим код

1. Репозиторий adolesson стартует **копией betty-rules** (текущий `HEAD`), с пометкой в README, из какого коммита взят код. После этого betty-rules замораживается как прототип; правки, сделанные там позже, переносятся вручную.
2. Код реорганизуется по зонам:
   ```
   src/
     app/            // корневой роутер, выбор входа, общие провайдеры
     ui/             // components/ui.tsx, Nav, токены и темы из styles.css
     teen/
       now/  start/  help/  practices/  profile/
       moe/          // ← бывший betty-rules: screens, content, state
     parent/
     shared-table/   // общий стол
     content/        // маршрут, фразы, квесты, диагностика
   ```
3. Ручной hash-роутер (`router.ts`) заменяется вложенными маршрутами `#/teen/moe/...`. Hash сохраняем на этапе 1, чтобы выкладка на GitHub Pages работала без серверных правил.

#### Что куда попадает

| betty-rules | В новом приложении | Изменения |
|---|---|---|
| `Now` («Что хочется иметь к концу?») | Главная раздела «Моё» | Переименовать: «Сейчас» теперь — чек-ин состояния |
| `Try`, `Thing`, `Things` (попытки, статусы) | «Моё» → затеи | Без изменений по смыслу |
| `Zine`, `Story`, `Slot` (истории, свои темы) | «Моё» → истории | `zine?stuck=1` открывается из жёлтого чек-ина как вариант «отвлечься на своё» |
| `Mantras` + `attitudes` (6 установок, которые можно переименовать и не принять) | «Я» → установки; фразы-опоры в Карточке подростка | Установки «Ошибки — опыт» и «Никто ничего не должен» прямо совпадают с планом; добавить установку про просьбу о помощи |
| `useMantraIdle` (мантры поверх экрана через 60 с) | Сохраняется, **но выключается** на экранах блока, дыхания, помощи и квестов | Перебивать фокус или кризисный экран нельзя |
| `Onboarding`, `Splash` | Общий онбординг подростка | 3 карточки «Мой курс» → 3–4 карточки нового приложения; выбор интересов и темы оставить |
| `Settings` (память браузера, выгрузка/загрузка, отзывы) | «Я» → данные | Текст про «только этот браузер» становится основой объяснения приватности личного слоя |
| `state/*` (`AppState` в localStorage, ключ `svoy-kurs`) | Личное хранилище подростка (IndexedDB) | Миграция схемы v1 → v2; импорт старой выгрузки через существующий `parseBackup` |
| Темы `lunar` (светлая) и `collage` (тёмная) | Темы всего приложения | По умолчанию — `collage`; у родителя спокойный вариант на тех же токенах |

#### Мосты между «Моим» и учёбой

Раздел остаётся пространством без оценок. Связи с учебной частью — только в одну сторону и по желанию:

- **Восстановление (Д).** Интересы из «Моего» подставляются в варианты отдыха на жёлтом/красном: «5 минут на эскиз образа» вместо безличного «отдохни».
- **Один шаблон старта.** Предложения в betty-rules уже устроены как «результат + 3 шага + можно неидеально». По тому же шаблону строится «Только первый шаг» для учёбы, чтобы у подростка был один привычный жест.
- **Рефлексия.** `Reflection` (что получилось, сколько минут, начала бы без этого) переиспользуется для учебного блока. Ответы на «начала бы без этого» — честный сигнал для модуля A, но только в её личном профиле.
- **«Хочу показать».** Статус `want-to-show` предлагает «Положить на общий стол» с предпросмотром. Это единственный путь, которым что-то из «Моего» попадает к родителям. Хороший повод для разговора не про учёбу (чек-лист §7: «был контакт не об учёбе»).

Что **не** делаем: не считаем время в «Моём» как «непродуктивное», не показываем родителю интересы и затеи без явного шага, не превращаем затеи в награду за учебные блоки (§7 черновика: отдых не награда за оценки).

#### Перенос данных

Данные betty-rules лежат в localStorage старого адреса (GitHub Pages), новое приложение их не увидит. Путь переноса: в старом приложении «Настройки → Выгрузить» → в новом «Я → Данные → Загрузить выгрузку „Моего курса“». Формат `svoy-kurs` v1 поддерживается при импорте.
