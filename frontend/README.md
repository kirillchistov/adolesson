# Каркас фронтенда

Копия [betty-rules](https://github.com/kirillchistov/betty-rules) на коммите `8003a2bc416903a2f4b6b3fd3af27c8747c51e0b` (`feat: restore mamtras`, 18.11.2026). Поздние правки betty-rules переносятся сюда вручную.

Личный слой остаётся на устройстве. Общий стол ходит в API через `src/api/`. В режиме разработки Vite проксирует `/api` на http://127.0.0.1:5001.

- Подросток: `#/teen/now` — чек-ин, старт и блок, точная просьба, дыхание, карточка, кризисный экран, карта «Где ломается» (`#/teen/map`). Чек-ины, блоки, локальные просьбы, карточка и баллы карты лежат в IndexedDB (`adolesson-teen`). На стол после предпросмотра уходят только цвет, выбранная просьба и фраза, которую подросток сама положила.
- Родитель: `#/parent/week` — недели 0–4, разговор, пауза, фразы, «Что вижу» и «Когда нужна помощь». Наблюдения и ответы модуля B лежат в `localStorage` (`adolesson-parent`).
- Общий стол: `#/parent/table` и `#/teen/table`. Семью создаёт родитель, подросток входит по ссылке `#/join/{token}`. В одном браузере одна сессия: вторая роль входит после выхода или на другом устройстве.
- «Моё»: `#/teen/moe/...` — затеи, истории, мантры, аватар. Данные в `localStorage` под ключом `svoy-kurs`. Выгрузка из старого «Моего курса» загружается в настройках «Моего». Аватар на сервер не уходит.

Код «Моего» — копия [betty-rules](https://github.com/kirillchistov/betty-rules) на коммите `8003a2bc416903a2f4b6b3fd3af27c8747c51e0b` (`feat: restore mamtras`, 18.11.2026). Поздние правки betty-rules переносятся сюда вручную.
