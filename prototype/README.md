# Прототип (этап 0)

Кликабельный прототип ключевых экранов для теста с подростком и родителем — см.
[app-concept.md §10](../docs/app-concept.md). Мок-данные, без сервера; обе роли живут в одном браузере
(`localStorage`). Откройте две вкладки — подростка и родителя, — и общий стол будет обновляться между ними.

`package.json` лежит в этой папке. Из корня репозитория:

```bash
make install
make dev         # http://127.0.0.1:5173, с телефона — сетевой адрес из вывода Vite
make lint        # oxlint
make build       # проверка типов и сборка в prototype/dist/
```

Те же скрипты из этой папки: `npm install`, `npm run dev`, `npm run lint`, `npm run build`.

## Экраны

| Подросток | Родитель | Общий |
|---|---|---|
| Сейчас — чек-ин цветом → одно действие | Неделя — маршрут 0–8 | Стол — цвет дня, договорённость, просьбы |
| Старт — «только первые 5 минут» → блок → одна строка | Перед разговором — чек-лист-фильтр | |
| Помощь — точная просьба с предпросмотром | Пауза — 20 с → 5 вдохов → 5–10 мин → возвращение | |
| Дыхание + «Остановиться — назвать — выбрать» | Фразы — карточки замены + подсказки к наблюдениям | |
| Карта барьеров — модуль A, радар 5 точек | | |
| Я — карточка, тема; Красный день; Помощь сейчас | | |

## Что прототип не делает

- Не разделяет устройства: в продукте личный слой подростка хранится только на её устройстве, а общий стол — на сервере.
- Нет входа и семьи, нет уведомлений, нет раздела «Моё» (перенос betty-rules — отдельный шаг).
- Тексты кризисного экрана — черновик, нужна вычитка специалистом.

Контент лежит в `src/content/` и ссылается на коды источников из [docs/sources.md](../docs/sources.md).
